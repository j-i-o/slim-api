# Slim API

Instrucciones para ejecutar la aplicación PHP localmente.

## Ejecutar la aplicación

1. Ir al directorio del proyecto:

```powershell
cd c:\Facultad\PHP\Proyecto\slim-api
```

2. Ejecutar el servidor PHP integrado:

```powershell
php -S localhost:8000 -t public
```

## Correr el servidor

1.  Ejecutar el siguiente comando:
```powershell
mysql -u root -p
```
